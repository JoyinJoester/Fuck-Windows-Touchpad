# Fuck-Windows-Touchpad

Windows 精确式触摸板（Precision Touchpad）的手势增强工具。接管系统默认手势，把三指、四指甚至五指的每一个动作都交给你自己定义。

单个 exe，绿色便携，不注入任何进程，崩溃后自动还原系统设置。

```
版本 1.1.0 · C++17 · Win32 + GDI+ · 无运行时依赖
```

## 功能

### 窗口管理
- **按住拖动窗口** —— 按住三指（或四指）移动光标下的窗口，macOS 同款体验；超边界自动回弹，标题栏始终可达
- **双指捏合缩放窗口** —— 张开放大、捏合缩小；以手指位置为中心，斜着捏按手指方向分轴缩放（横向捏只改宽度、45° 等比），带橡皮筋过冲
- **三指左右滑动** —— 与相邻窗口互换位置
- 窗口最大化 / 最小化 / 关闭

### 手势映射矩阵（36 个槽位）

| | 轻点 | 双击 | 左滑 | 右滑 | 上滑 | 下滑 | 四角 | 左右边缘 |
|---|---|---|---|---|---|---|---|---|
| **三指** | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| **四指** | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| **五指** | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

每个槽位可独立绑定 30+ 种动作：

- **窗口**：与左右窗口互换、任务视图、显示桌面、最大化、最小化、关闭
- **切换**：Alt+Tab 上/下一个窗口、浏览器标签页前/后切换、虚拟桌面前/后切换
- **系统**：锁屏、截图（Win+Shift+S）、任务管理器、全屏（F11）
- **声音媒体**：音量增减、静音、播放/暂停、上一曲/下一曲
- **编辑**：复制、粘贴、剪切、撤销、全选
- **自定义快捷键** —— 在界面上直接按键盘录制任意组合键（Esc 取消）
- **启动程序** —— 文件选择框指定任意 exe / lnk / bat

内置规则：只绑双击时单击立即触发不等待；绑了双击时单击等 320ms 确认；角部轻点优先于普通轻点；边缘滑动优先于中间滑动——都没绑则自动回落，开一个功能不会弄坏另一个。

### 双指
捏合缩放窗口（可关），缩放灵敏度、起手死区、缩放方向（等比 / 跟随手指 / 仅横向 / 仅纵向）全部可调。

### 高级
- 滑动触发距离（按毫米显示，不是裸设备单位）
- 斜滑容差（按角度显示）
- 双指起手死区
- 轻点最长按住时间、轻点位移容差（按毫米显示）
- 边缘区域宽度
- 双击判定窗口
- **触点实时图** —— 直接画出触摸板上的每一个触点，手势"没反应"时一眼看出是没读到还是被识别器拒了
- 运行状态：设备名、帧率、手势计数

### 其他
- 浅色 / 深色 / 跟随系统主题
- 开机自启（登录后静默进托盘）
- 弹性布局窗口，1.5× 缩放下到 4K 都清晰
- 关闭到托盘，不占任务栏

## 编译

需要 [MSYS2](https://www.msys2.org/) 的 MinGW-w64 工具链，无 CMake：

```bash
# 直接编译
/c/msys64/mingw64/bin/g++.exe -std=c++17 -O2 -Wall -Wextra -Isrc \
    -DUNICODE -D_UNICODE -finput-charset=UTF-8 \
    src/*.cpp -o build/Fuck-Windows-Touchpad.exe \
    -mwindows -municode \
    -lhid -lsetupapi -luser32 -ladvapi32 -ldwmapi -lshell32 \
    -lws2_32 -lgdiplus -lole32

# 或者
mingw32-make        # 构建
mingw32-make dist   # 构建并打包到 dist/
mingw32-make run    # 构建并启动
```

输出为 GUI 子系统单文件（约 850 KB），双击即用，无控制台窗口。

## 使用

1. 运行 `Fuck-Windows-Touchpad.exe`，窗口弹出后程序接管触摸板手势（系统自带的四指/三指手势会被暂时关闭并记录原值）
2. 在**手势**页为每根手指绑定动作，改动立即生效
3. 右键托盘图标或直接关窗即可退出——**正常退出和崩溃都会自动还原系统手势设置**，不用手动改注册表
4. 配置保存在 exe 同目录的 `tp_gestures.ini`，全部是可读的 `key = value`

命令行参数：

```
--minimized     启动时不弹窗口（自启动用）
-v              详细日志
--log           日志写文件
--windows       列出顶层窗口
--test-drag     拖动自检
--test-crash    崩溃还原自检
```

## 安全设计

- **不注入进程、不改驱动、不装键盘钩子**——只通过 Raw Input 读触摸板，用 SendInput 发合成键
- 接管系统手势前把注册表原值记到临时快照文件，**异常退出（包括崩溃和被强杀）下次启动时自动恢复**，正常退出时立即恢复
- 拒绝关闭宿主终端窗口，避免误关看起来像崩溃
- 配置写入使用临时文件 + 替换，断电不丢配置

## 自检工具（tools/）

| 工具 | 作用 |
|---|---|
| `pinch_selftest` | 14 组引擎单元测试：分轴捏合、45° 等比、轻点/长按/边缘判定 |
| `gesture_selftest` | 回放真实触摸板录制（.log），验证解码与识别 |
| `pinch_win_test` | 窗口拖动/缩放边界测试 |
| `shot` | 截图工具，支持 `--tour` 四页巡检、`--resize` 布局验证 |
| `tp_probe` | 触摸板探针，dump HID 报文 |

```bash
# 示例：跑捏合自检
g++ -std=c++17 -O2 -Isrc -DUNICODE -D_UNICODE tools/pinch_selftest.cpp \
    src/GestureEngine.cpp src/Touchpad.cpp \
    -o build/pinch_selftest.exe -mconsole -luser32 -lhid -lsetupapi
./build/pinch_selftest.exe
```

## 已知限制

- 需要 Windows 精确式触摸板（大多数 2016 年后的笔记本都符合；控制面板 → 触摸板里能看到"精确式触摸板"字样）
- 手指数量超过触摸板上限（通常是 4 或 5）时按上限处理
- 下拉菜单超过屏幕高度时会滚动显示，但没有滚轮惯性
- 拖动窗口暂不支持 Aero Snap 贴边分屏
- 无单实例保护：同时开两个 exe 会争抢 Raw Input

## 项目结构

```
src/
  main.cpp            入口、Raw Input 循环、手势分发
  Touchpad.*          HID 设备枚举与能力查询
  RawInputSource.*    WM_INPUT 报文接收
  GestureEngine.*     手势识别：滑动 / 轻点 / 拖动 / 捏合四通道
  WindowManager.*     窗口拖动、捏合缩放、互换
  Action.*            动作执行（合成键、启动程序、窗口操作）
  Config.*            36 槽位绑定表 + ini 读写与版本迁移
  Preflight.*         系统手势接管与崩溃还原
  UiWindow.*          GDI+ 自绘设置界面（手势/窗口/高级/关于）
  EventLog.*          运行日志
```
